# Agro Jekpe-jek — нативное Android-приложение (тестовая сборка)

Первый шаг к отдельному Android/iOS-приложению для «⚔️Agro Jekpe-jek» — того же баттла на
знание агрономии, что и в Telegram-боте `@agroexam_bot`, но с полноценным нативным интерфейсом
(Flutter), а не веб-страницей в обёртке.

## Почему так устроено

В этом репозитории — только код приложения (`lib/`, `pubspec.yaml`) и workflow сборки
(`.github/workflows/build-apk.yml`). Вся Android/Gradle-обвязка НЕ хранится здесь — она
генерируется заново самим `flutter create` прямо в GitHub Actions при каждой сборке, поверх
неё накладывается код из `lib/`. Так надёжнее: эта обвязка собирается официальным
инструментом в чистом окружении, а не пишется вручную без возможности проверить её локально.

Собирается в облаке (GitHub Actions) — локально Android SDK/Flutter ставить не нужно.

## Как собрать APK

Сборка запускается автоматически при пуше в `main`, либо вручную:

```bash
gh workflow run build-apk.yml
```

Готовый `.apk` (debug-сборка, для тестовой установки на свой телефон — НЕ для публикации
в Play Store) появляется в разделе Actions → последний run → Artifacts.

## Бэкенд

Приложение обращается к тому же Cloudflare Worker, что и Telegram-бот:
`https://examagro-bot.markanlife.workers.dev` — общая база данных, статистика и игровая логика,
без отдельной синхронизации.
